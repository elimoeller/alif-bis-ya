# Alif bis Yāʾ

Arabisches Alphabet spielerisch lernen: ein 7-Tage-Lernpfad mit allen 28 Buchstaben, den Vokalzeichen (Ḥarakāt) und Lesewörtern. Dazu ein freier Modus zum Üben nach Formgruppen und ein unauffälliger Seminar-Modus.

- läuft komplett im Browser, ohne Anmeldung und ohne Tracking
- funktioniert offline und lässt sich auf dem Handy als App installieren
- der Lernstand bleibt im eigenen Browser
